# Nova Store — website prototype

A mobile-first futuristic landing page for a future African app marketplace, now including a **Nova Ideas Hub** preview.

## Run locally
Open `index.html` in a modern browser. Google Fonts load when internet is available.

## Ideas Hub preview
- Visitors can add an idea title, category and short description.
- Visitors can support an idea once per page session.
- Submissions and votes are held only in the current page. Refreshing clears them.
- No information is sent to a server or published online.

## Publish with GitHub Pages
1. Create a GitHub repository named `NovaStore`.
2. Upload `index.html`, `style.css`, `script.js` and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for the published site link to appear in the Pages section.

## Important before a public launch
This is a front-end prototype only. Sample app listings and community ideas are fictional. There is no backend, account system, permanent idea storage, public submission service, moderation workflow, APK hosting, malware scanning or real app download functionality.

Before accepting public submissions, add clear submission terms, ownership/licensing rules, privacy protections, reporting and moderation tools, and secure server-side storage. Do not promise that an idea is legally protected simply because it is submitted here. Do not upload real APKs until developer verification, malware scanning, signing checks and update integrity checks are implemented.
